# Структура таблицы news

**Важно:** Этот файл содержит актуальную структуру таблицы `news` после миграции 021 (мультиязычность i18n). При изменении структуры таблицы обновляйте этот файл.

## Назначение

Новости (статьи) с мультиязычным контентом. Язык оригинала задаётся полем `source_lang`; переводы заголовка, краткого описания и текста хранятся в JSON-полях `*_i18n` по ключам локалей. Поддерживаемые локали: `en`, `ru`, `es`, `ar`, `zh`, `hi`, `fr`, `pt`, `he`, `de`.

## Колонки таблицы

| Колонка | Тип | Nullable | Описание |
|---------|-----|----------|----------|
| `id` | CHAR(36) | NO | UUID новости, первичный ключ |
| `source_lang` | VARCHAR(10) | NO | Язык оригинала (один из поддерживаемых кодов) |
| `title_i18n` | JSON | YES | Заголовок по локалям: `{ "en": "...", "ru": "...", ... }` |
| `short_description_i18n` | JSON | YES | Краткое описание по локалям |
| `text_i18n` | JSON | YES | Текст статьи по локалям |
| `image_url` | VARCHAR(2048) | YES | Ссылка на изображение (http/https) |
| `published_at` | DATETIME | YES | Дата и время публикации |
| `view_count` | INT | NO | Счётчик просмотров (по умолчанию 0) |
| `created_at` | DATETIME | YES | Дата создания записи |
| `updated_at` | DATETIME | YES | Дата последнего обновления |

**Примечание:** Отдельных колонок `title`, `short_description`, `text` в таблице нет — они удалены миграцией 021. Вся текстовая часть хранится только в `*_i18n`.

## Формат ввода контента (API)

При создании/редактировании контент передаётся одним полем `content` с разделителем `[|||]`:
```
title[|||]short_description[|||]text
```
Сервис перевода парсит строку, переводит каждую часть на все локали и сохраняет в `title_i18n`, `short_description_i18n`, `text_i18n`.

## Связанные таблицы

- **`news_likes`** — лайки пользователей по новостям (пары `news_id`, `user_id`). Количество лайков не хранится в `news`, а считается по этой таблице.

## Миграции
