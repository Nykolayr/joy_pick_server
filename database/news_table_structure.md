# Структура таблицы news

**Важно:** Этот файл содержит актуальную структуру таблицы `news` после миграций 021 (i18n) и 022 (типы статей). При изменении структуры таблицы обновляйте этот файл.

## Назначение

Новости (статьи) с мультиязычным контентом. Два типа: **simple** (массив фото) и **from_request** (привязка к заявке). Язык оригинала — `source_lang`; переводы — в JSON `*_i18n`. Для статей типа `from_request`: при выдаче приложению проверяется статус заявки; если заявка в архиве — статья удаляется из БД и в ответ не попадает.

## Колонки таблицы

| Колонка | Тип | Nullable | Описание |
|---------|-----|----------|----------|
| `id` | CHAR(36) | NO | UUID новости, первичный ключ |
| `type` | VARCHAR(20) | NO | Тип статьи: `simple` \| `from_request` (по умолчанию `simple`) |
| `source_lang` | VARCHAR(10) | NO | Язык оригинала (один из поддерживаемых кодов) |
| `title_i18n` | JSON | YES | Заголовок по локалям |
| `short_description_i18n` | JSON | YES | Краткое описание по локалям |
| `text_i18n` | JSON | YES | Текст статьи по локалям |
| `image_urls` | JSON | YES | Массив URL фото (только для `type=simple`). Формат: `["url1", "url2", ...]` |
| `request_id` | VARCHAR(36) | YES | ID заявки (только для `type=from_request`), связь с `requests.id` |
| `published_at` | DATETIME | YES | Дата и время публикации |
| `view_count` | INT | NO | Счётчик просмотров (по умолчанию 0) |
| `created_at` | DATETIME | YES | Дата создания записи |
| `updated_at` | DATETIME | YES | Дата последнего обновления |

Колонки `title`, `short_description`, `text`, `image_url` в таблице нет (удалены миграциями 021 и 022).

## Формат ввода контента (API)

При создании/редактировании контент передаётся полем `content` с разделителем `[|||]`:
- **simple:** `title[|||]short_description[|||]text` — три части в `title_i18n`, `short_description_i18n`, `text_i18n`.
- **from_request:** `theme[|||]text` — две части: тема сохраняется в `title_i18n`, текст в `text_i18n`, `short_description_i18n` пустой. В ответе приложению отдаются поля `theme` и `text`.

## Связанные таблицы

- **`news_likes`** — лайки пользователей по новостям (пары `news_id`, `user_id`). Количество лайков считается по этой таблице.
- **`requests`** — для статей `type=from_request` поле `request_id` ссылается на заявку. При переходе заявки в статус `archived` статья при следующем запросе из приложения удаляется из `news`.

## Миграции

- **021_news_i18n.sql** — добавлены `source_lang`, `title_i18n`, `short_description_i18n`, `text_i18n`; удалены `title`, `short_description`, `text`.
- **022_news_types.sql** — добавлены `type`, `image_urls`, `request_id`; перенос данных из `image_url` в `image_urls`; удалена колонка `image_url`.
